# ファイル転送ソフト 機能設計書

## 1. 目的

本ソフトウェアは、macOS 向けの安全で分かりやすいファイル転送クライアントである。Cyberduck の「接続先をブックマークから選び、リモートファイルを Finder のように操作し、確実に転送を管理する」体験を設計上の基準にする。

実装は **Tauri 2 + Rust** を基盤とする。`r-shell` は機能・実装パターンを参照するだけであり、製品コードから参照ディレクトリへのリンク、実行時依存、相対パス参照は一切持たない。

## 2. スコープ

### 初回リリース（MVP）

| 領域 | 機能 |
| --- | --- |
| 接続 | SFTP、FTP、Explicit FTPS、HTTPS WebDAV、Amazon S3／S3互換、Samba／SMB 2/3、Google Drive、ブックマーク、接続履歴 |
| 認証 | パスワード、SSH 公開鍵、パスフレーズ、ホスト鍵の初回確認、ユーザー所有のGoogle OAuth Client ID |
| キー管理 | ローカル `~/.ssh` の鍵メタデータ一覧と、接続への鍵選択 |
| ファイル操作 | 一覧、移動、検索、アップロード、ダウンロード、キャッシュ経由の外部編集、フォルダ作成、名前変更、カット／コピー／ペースト、削除、ファイル情報変更 |
| 転送 | キュー、進捗、速度、残り時間、停止、再開、失敗時の再試行、競合解決 |
| 同期 | ローカル/リモートディレクトリの差分確認と片方向同期 |
| 利用環境 | macOS、英語・日本語・简体中文、ライト/ダーク外観 |

### 初回リリースの対象外

- Backblaze B2など、個別アダプタをまだ実装していないクラウドストレージ
- 端末エミュレータ、リモートデスクトップ、サーバー監視
- 双方向同期、スケジュール実行、共同編集
- Finder 拡張・システム常駐メニュー

これらはプロトコル抽象化と転送エンジンの安定後に追加する。

## 3. 想定ユーザーと主な利用フロー

| ユーザー | 目的 | 基本フロー |
| --- | --- | --- |
| Web 制作者 | 公開ファイルを安全に更新 | ブックマークを開く → ローカルからドロップ → 転送完了を確認 |
| 開発者 | 成果物・ログを回収 | SFTP 接続 → リモートを検索 → ダウンロード → Finder で開く |
| 運用担当者 | ディレクトリを配布 | 同期プレビュー → 差分と競合を確認 → 実行 → 履歴を確認 |

## 4. 画面設計

### 4.1 メインウィンドウ

macOS の標準ツールバーと Finder に近い情報構造を採用する。中央のリモートブラウザを主役にし、転送状況は常に確認できるが作業を妨げない位置に置く。

```text
┌──────────────────────────────────────────────────────────────────┐
│ ツールバー: 新規接続 | 戻る/進む | パス | 更新 | 検索 | 転送数     │
├───────────────┬──────────────────────────────────────────────────┤
│ ブックマーク  │ 接続タブ                                          │
│ ・お気に入り  ├──────────────────────────────────────────────────┤
│ ・履歴        │ パンくず / 表示切替                              │
│ ・タグ        ├──────────────────────────────────────────────────┤
│               │ 名前 | サイズ | 更新日 | 種類 | 権限              │
│               │ リモートファイル一覧（リスト/アイコン表示）       │
├───────────────┴──────────────────────────────────────────────────┤
│ 転送キュー: 状態 | ファイル | 方向 | 進捗 | 速度 | 残り時間       │
└──────────────────────────────────────────────────────────────────┘
```

- 左サイドバー: ブックマーク、履歴、タグ。ドラッグで並べ替え、フォルダで整理できる。
- 接続タブ: 接続ごとに 1 タブ。未保存の転送があるときは閉じる前に確認する。
- リモートブラウザ: フォルダのダブルクリックで階層を移動し、ファイルのダブルクリックまたはEnterで指定済み外部エディタを開く。三点リーダーは名称変更を含むファイル情報画面を直接開き、右クリックではカット、コピー、ペースト、削除、ダウンロード、ファイル情報変更のコンテキストメニューを表示する。操作はリスト・アイコン・カラム表示で共通とする。
- 転送キュー: 下部パネルは起動時に閉じ、転送開始時に自動展開し、実行中の転送がなくなると自動で閉じる。ユーザーが明示的に開閉した後は、そのセッション中は自動制御よりユーザーの選択を優先する。実行中・待機・完了・失敗を分離して確認できる。
- ローカルファイル: Finder からのドラッグ&ドロップを MVP の主経路とし、後続で左右ペイン表示を追加する。

### 4.2 新規接続シート

接続先、認証、詳細設定の三段階に分ける。必須項目のみを初期表示し、詳細設定は展開式にする。

| 区分 | 項目 |
| --- | --- |
| 接続先 | 表示名、プロトコル、サーバー、ポート、初期パス |
| 認証 | ユーザー名、パスワードまたは鍵ファイル、パスフレーズ |
| 詳細 | 接続タイムアウト、Keep Alive、プロキシ、FTP passive mode、TLS 証明書方針 |

ブックマークの「表示名」はサーバーアドレスと分離する。同じサーバーへ用途やユーザーが異なる複数のブックマークを、利用者が判別できる名称で保存できるようにする。

### 4.3 環境設定

ツールバーの環境設定から、特定のブックマークに属さない共通設定を変更する。初期実装では表示言語、新規接続の既定プロトコル、同名ファイルの既定動作、削除確認、転送結果通知、リモートファイルを開く外部エディタを管理する。設定データはブックマークとは別の名前空間で永続化し、今後の転送・表示・セキュリティ設定を追加できる構造にする。

- プロトコルを選ぶと既定ポートを提案する（SFTP 22、FTP 21、Explicit FTPS 21、HTTPS WebDAV 443）。
- 初回接続時は SSH ホスト鍵の fingerprint を明示し、信頼または中止を選べる。保存済み fingerprint と異なる接続は中止する。
- 保存する場合のみブックマーク名とタグを入力する。秘密情報は OS のキーチェーンに保存し、設定ファイルへ平文で書かない。

### 4.3 同期プレビューと実行

同期を開始する前に、ローカルとリモートの差分を表形式で提示する。方向、ファイル名、サイズ、予定操作（追加・更新・削除なし）を確認し、ファイル競合ごとにスキップまたは転送元優先を選択してから実行する。除外パターンは改行区切りで保持する。実行直前に Rust 側で差分を再計算し、古くなった計画や安全でない相対パス、シンボリックリンク経由のローカル書き込みを拒否する。実行は停止でき、結果を履歴として保存する。MVP では安全のため削除操作を同期計画に含めない。

## 5. 機能要件

### FR-01 接続とブックマーク

- SFTP、FTP、Explicit FTPS、HTTPS WebDAV、Amazon S3／S3互換ストレージへ接続できる。
- ブックマークの作成、編集、複製、削除、タグ付け、フォルダ整理、検索ができる。
- ブックマークはバージョン付き JSON へ書き出し・読み込みできる。同一 ID・同一接続先は更新し、新しい ID は追加する。同一 ID でも接続先が異なる場合は、Keychain の認証情報との誤結合を避けるため新しい ID で追加する。
- ブックマークごとに、リモート初期ディレクトリと組み合わせる任意のローカルディレクトリを選択・解除できる。この対応関係をrsync互換差分同期の既定値として利用する。
- 前回のリモートパス・表示方式・ソート条件をブックマーク単位で復元する。
- 接続失敗は原因を利用者向けの文言に変換し、再試行できる。

### FR-02 リモートファイルブラウズ

- 一覧には名前、サイズ、更新日時、パーミッションを既定表示し、所有者、グループ、種類を任意で追加表示する。名前と操作用の三点リーダーは常に表示する。
- リモート項目は一時ローカルファイルを生成せず、拡張子から画像、動画、音声、文書、表計算、コード、設定データ、圧縮ファイル、リンクを判定し、全表示方式で形と色の異なるアイコンを表示する。ファイル名は背景に対する最大コントラスト色で表示する。
- リスト表示、アイコン表示、フォルダ階層を右方向へ展開するカラム表示を切り替えられ、選択した表示方式を次回起動時に復元する。
- 全表示方式でCommand/Ctrlクリックによる個別追加・解除とShiftクリックによる範囲選択を提供する。複数選択のファイル情報画面では、個別の名称変更を無効にし、パーミッション、更新日時、所有者、グループなど選択項目へ共通適用できる属性だけを一括変更する。
- パンくず、戻る/進む、親フォルダ、パス直接入力、更新、名前検索を提供する。
- リストの列見出しをクリックすると、その列で昇順・降順を切り替える。列見出しの右クリックメニューでは、名前と操作列を除く各列の表示・非表示を選択でき、表示設定を次回起動時に復元する。
- フォルダ作成、名前変更、削除を提供する。削除は対象数とパスを表示して確認を求める。
- 同一接続内のカットは安全なrename、コピーは一時キャッシュを介した再帰転送として実行する。シンボリックリンクは追跡せず、コピー先の既存項目を暗黙に上書きしない。
- 三点リーダーまたは右クリックから開くファイル情報画面では、名称、種類、サイズ、パーミッション、更新日時、所有者、グループを一括確認する。名称は全プロトコルで変更できる。SFTPはSETSTATでパーミッション、更新日時、数値UID/GIDを変更し、FTP/FTPSはサーバーが対応するSITE CHMOD／MFMTでパーミッションと更新日時を変更する。WebDAV／S3では移植可能な属性変更がないことを明示し、名称変更だけを有効にする。

### FR-02A SSH キー・マネージャー

- macOS ユーザーの `~/.ssh` を読み、秘密鍵ファイル名、パス、対応する `.pub` ファイルの有無を表示する。
- 秘密鍵と`.pub`公開鍵をそれぞれ独立した項目として、異なるアイコン、色、種別バッジで表示する。対応する鍵の存在を相互に示し、SFTP接続へ選択できるのは秘密鍵だけとする。
- 秘密鍵の内容、パスフレーズ、鍵素材は UI や IPC の戻り値へ含めない。
- `config`、`known_hosts`、`authorized_keys`、隠しファイル、`.pub` 単体は鍵候補から除外する。
- 選択した鍵のパスを新規接続シートへ引き渡し、SFTP の公開鍵認証に使用できる。

### FR-03 転送

- Finder からのファイル/フォルダのドロップ、またはリモート項目のダウンロード操作で転送ジョブを作成する。
- リモートのファイルまたはフォルダを選択するとアプリ専用キャッシュへ準備し、リスト・アイコン・カラム表示からFinderやデスクトップへコピー操作としてドラッグできる。フォルダは空フォルダを含めて再帰取得し、安全のためシンボリックリンクは追跡しない。Finderがドロップ後もコピー元を遅延参照できるよう成功時は30分の猶予後、取消時は即時に一時キャッシュを削除する。
- フォルダ転送は再帰的にジョブへ展開し、空フォルダも作成する。
- 状態は `queued`、`preparing`、`running`、`paused`、`completed`、`failed`、`cancelled` とする。
- 各ジョブに進捗率、転送済みバイト、速度、残り時間、エラー、再試行回数を表示する。
- 同名ファイルの方針は「確認」「上書き」「スキップ」「別名保存」を選択でき、同一キュー内で適用できる。
- 完了済み・失敗済みジョブは履歴として保持し、手動で消去できる。
- 環境設定で macOS アプリケーションを外部エディタとして選択できる。リモートファイルはダブルクリックまたはEnterでアプリ専用キャッシュへダウンロードしてから開き、通常の「開く」操作ではダウンロード保存先を尋ねず、元ファイルも直接編集しない。
- キャッシュ内容のハッシュ変化が750ms以上安定した時点を保存とみなし、接続中の同じリモートパスへ自動的に上書きアップロードする。編集状況と失敗を転送パネルに表示する。
- 編集セッションが継続しているファイルを再度開いた場合は、新しいキャッシュを作成せず、監視中の同じ安全なキャッシュを外部エディタで再表示する。
- 編集終了時は未送信変更やアップロード中でないことを検証してキャッシュを削除する。キャッシュが通常ファイルでなくなった場合やシンボリックリンクへ置換された場合はアップロードしない。

### FR-04 同期

- ローカルとリモートを再帰走査し、相対パス・種類・サイズ・更新日時を比較する。
- ローカル→リモート、またはリモート→ローカルの一方向同期を実行できる。
- 実行前に差分を確認し、除外パターン（例: `.DS_Store`、`node_modules/**`）を設定できる。
- ファイルごとの競合は自動解決せず、差分一覧でスキップまたは転送元優先を選択させる。ファイルとディレクトリの種別競合は実行しない。
- 同期計画は実行直前に再検証し、削除を行わず、安全でないパスを拒否する。
- 実行を停止でき、完了・失敗・取消と項目別結果を履歴へ保存して消去できる。

### FR-05 言語・アクセシビリティ

- 表示文言は英語（`en`）、日本語（`ja`）、简体中文（`zh-CN`）を同一キーで管理する。
- OS 言語に追従する初期値と、アプリ内での上書き設定を提供する。
- すべての操作にキーボードフォーカスを持たせ、アイコンボタンにはアクセシブルな名称を設定する。
- 色だけで転送状態を表現せず、アイコンとテキストを併用する。

## 6. 技術設計

### 6.1 構成

| 層 | 採用技術 | 責務 |
| --- | --- | --- |
| UI | Tauri 2 WebView + TypeScript フロントエンド | 画面、状態、i18n、ドラッグ&ドロップ、IPC 呼び出し |
| アプリケーション | Rust / Tauri Commands | 入力検証、接続・転送・ブックマークのユースケース |
| ドメイン | Rust | 転送キュー、競合判定、同期計画、接続状態遷移 |
| インフラ | Rust async + プロトコルアダプタ | SFTP、FTP、FTPS、WebDAV、ローカル FS、Keychain、SQLite |

```text
UI ── invoke/event ──> Tauri Commands ──> TransferService
                                      ├──> ConnectionRegistry
                                      ├──> ProtocolAdapter (SFTP / FTP / FTPS / WebDAV)
                                      ├──> BookmarkRepository (SQLite)
                                      └──> SecretStore (macOS Keychain)
```

参照実装にある SFTP/FTP 接続・一覧・アップロード/ダウンロード・再帰走査の知見は移植対象とする。ただし端末、RDP/VNC、サーバー監視、WebSocket PTY は本製品に含めず、転送中心の Rust モジュールへ再設計する。

### 6.2 Rust モジュール案

| モジュール | 責務 |
| --- | --- |
| `models` | Bookmark、ConnectionProfile、RemoteEntry、TransferJob、SyncPlan の直列化可能な型 |
| `protocol` | `RemoteFileSystem` trait と SFTP / FTP / FTPS / WebDAV / S3 実装 |
| `connection` | 接続生成、ライフサイクル、ホスト鍵/TLS 信頼判定 |
| `transfer` | キュー、並列数制御、停止/再開/再試行、進捗イベント |
| `sync` | 再帰差分、glob 除外規則、同期計画生成と安全性検証 |
| `storage` | SQLite のブックマーク・設定・履歴、Keychain の秘密情報 |
| `commands` | UI に公開する最小限の Tauri command |

### 6.3 IPC 契約（初案）

| Command / Event | 目的 |
| --- | --- |
| `bookmarks_list`, `bookmark_save`, `bookmark_delete` | ブックマーク管理 |
| `connection_connect`, `connection_disconnect` | 接続の開始・終了 |
| `remote_list`, `remote_create_directory`, `remote_rename`, `remote_delete` | リモート操作 |
| `transfer_enqueue_upload`, `transfer_enqueue_download` | 転送ジョブ登録 |
| `transfer_pause`, `transfer_resume`, `transfer_cancel`, `transfer_retry` | キュー制御 |
| `remote_edit_open`, `remote_edit_reopen`, `remote_edit_poll`, `remote_edit_close` | 外部エディタ用キャッシュの作成、再表示、保存検知と上書き、終了 |
| `sync_preview`, `sync_execute`, `sync_history_list`, `sync_history_clear` | 差分確認、同期実行、実行履歴管理 |
| `workspace_link_set`, `workspace_link_resolve` | ウインドウ単位の連動基準設定と対応ディレクトリの解決 |
| `workspace_places_list`, `workspace_place_save`, `workspace_place_delete` | Placesの一覧、登録・名称変更、解除 |
| `workspace_document_load`, `workspace_document_save` | 呼び出し元ウインドウのタブと表示設定を検証して読み書き |
| `workspace://places-changed` | Places変更時に他のウインドウの一覧を更新 |
| `workspace://link-invalidated` | 同じ接続IDの再登録／切断時に、影響を受けるウインドウへ連動解除を通知 |
| `transfer://progress`, `sync://progress`, `transfer://state`, `connection://state` | UI へ送るイベント |

すべての command は構造化した成功値または利用者向けエラーコードを返す。ローカルパスとリモートパスは Rust 側で検証し、UI から渡された文字列をシェルコマンドとして実行しない。

## 7. データとセキュリティ

- ブックマーク、UI 設定、非機密の転送履歴はアプリ専用 SQLite に保存する。
- パスワード、秘密鍵のパスフレーズ、プロキシ認証情報は macOS Keychain にのみ保存する。
- Keychain内では資格情報を名前空間付きの単一保管庫へまとめ、アプリ起動中は一度だけ読み込む。同値の再保存を避け、macOSの項目単位の認証要求を抑える。旧形式の項目は使用時に段階移行し、削除済み資格情報は移行元から復活しないよう削除状態も保管する。
- ブックマークの書き出しにはパスワード、秘密鍵の内容、パスフレーズを含めない。読み込み時は形式、件数、プロトコル、ポート、必須項目を検証する。
- SSH は未知のホスト鍵・変更されたホスト鍵を明確に区別し、変更時は自動接続しない。
- FTPS は既定で証明書検証を有効にする。例外を許可する場合も、接続先単位で明示的な利用者操作を必要とする。
- WebDAV は HTTPS のみを許可し、TLS証明書検証を無効化する製品設定を設けない。Basic認証のパスワードはmacOS Keychainに保存する。
- ログにはパスワード、トークン、秘密鍵内容を絶対に出力しない。
- 削除・上書き・同期による変更前には確認ダイアログを出し、対象・件数・方針を表示する。

## 8. 品質要件と受け入れ条件

- 転送中でも UI は操作可能であり、進捗イベントを滑らかに反映する。
- 接続断・アプリ再起動・一時ネットワーク障害でも、失敗したジョブの理由と再試行操作が残る。
- 単一ファイル、複数ファイル、階層フォルダ、空フォルダ、Unicode 名、空白を含むパスをテスト対象に含める。
- SFTP、FTP/FTPS、WebDAV のそれぞれで、一覧・作成・改名・削除・アップロード・ダウンロードを自動テストする。WebDAVは標準仕様向けfixtureとNextcloudの両方で検証する。
- 英語・日本語・简体中文で翻訳キーの不足を CI で検出する。
- 新規 UI は macOS の標準ショートカット、フォーカス、ダークモードに適合する。

## 10. デュアルペインの連動ナビゲーションとPlaces

### 10.1 連動ナビゲーション

- 中央のリンクボタンを押した時点の左右のフォルダを、それぞれの基準にする。ローカル同士、ローカルとリモート、リモート同士に対応する。
- 基準フォルダの組み合わせはRustの`AppState`がTauriウインドウのラベル単位で管理する。他のウインドウと共有せず、ウインドウ破棄時に解除する。WebViewは表示状態と移動要求のみを扱う。
- 同じ接続IDが別のウインドウなどから再登録・切断された場合は、その接続を使用するウインドウの連動だけをRust側で解除し、対象ウインドウへ通知する。他の接続を使うウインドウは維持する。
- 一方で階層を移動すると、もう一方の基準から同じ相対名のフォルダを探す。Google Driveでは接続先ごとに異なる項目IDを使い回さず、表示名で一意なフォルダを探して、その接続先のID付きパスを組み立てる。
- 対応フォルダがない、同名が複数ある、通常フォルダでない、基準の外へ移動した、接続先が変わった場合は停止する。フォルダの作成やファイルの転送は行わず、対応先を推測しない。停止理由はリンクボタンのツールチップと読み上げ用ステータスへ表示する。
- 再開時は現在の左右のフォルダを新しい基準にする。基準設定・解除を順序通りに処理し、遅い応答で新しい移動を上書きせず、連動による移動を再度送り返さない。
- ローカル側は基準のcanonical path内に限定し、対応先の途中にシンボリックリンクがある場合は追跡しない。連動は再起動時に自動復元しない。

### 10.2 Places

- 各ペインの接続状態行の下に、同じ高さのPlacesバーを表示する。星ボタンで現在のフォルダへ名称を付けて登録し、登録先をクリックして移動する。
- 登録先の右クリック、または現在地の星ボタンから、名称変更と登録解除を行う。操作説明はツールチップにまとめる。
- Rustの`workspace`モジュールがアプリデータ内の`workspace.sqlite3`へ、ID、名称、ローカル／リモートの区別、ブックマークID、パスを保存する。資格情報、秘密鍵、接続セッションは含めない。
- ローカルの場所はローカルペイン間で共有し、リモートの場所は現在接続しているブックマークに限定して表示する。場所のクリックで別のサーバーへ自動接続しない。
- 名称は1〜128文字、合計200件までとし、同じ接続先・パスの再登録は名称の更新として扱う。SQLiteのWALとbusy timeoutで複数ウインドウからの操作を扱い、変更時はTauriイベントで一覧を更新する。
- UIの見出し、操作名、停止理由は日本語・英語・简体中文で提供する。

### 10.3 タブとワークスペースの復元

- ツールバー直下に最大32件のタブを表示する。＋／⌘T（Ctrl+T）で追加、×／⌘W（Ctrl+W）で終了し、最後のタブ終了後は空のタブを残す。タブ名はダブルクリックで編集でき、Enterで確定、Escapeで取り消す。タブにフォーカスして左右矢印／Home／Endでも選択できる。
- タブには名称、主ペインのローカル／リモート種別と接続状態を表示する。名称未設定時はブックマーク名を使う。多数のタブは横スクロールし、選択したタブが見える位置へ移動する。
- 保存するのはタブID・名称、主／補助ペインの種別・ブックマークID・パス、デュアルペイン有無・左右配置・分割比率、主ペインの表示方式・列幅・列表示・ソートである。補助ペインとローカルペインの表示は既存のリスト方式を維持する。ファイル一覧、選択内容、検索、接続セッション、資格情報は永続化しない。
- Rustの型付き文書（version 1）を`workspace.sqlite3`の`workspaces`テーブルへ保存する。ウインドウラベルはJavaScriptから指定させず、Tauriの呼び出し元から取得する。未定義フィールド、無効な文書バージョン、重複ID、上限超過、無効なパス・レイアウトを拒否する。
- メインウインドウは前回の文書を復元する。追加ウインドウは独立した新規ワークスペースで開き、別ウインドウの文書を上書きしない。終了した追加ウインドウ群の自動再生成は対象外。
- 同一起動中は接続を再利用できるが、再起動時にはリモートペインを未接続表示にする。明示的な「再接続」で既存の認証フローを使い、成功後にタブのパスへ戻る。認証情報の自動取得はしない。タブの復元パスをブックマークの初期パスへ書き戻さない。
- タブ切り替え時に古い一覧・カラム・連動移動の要求とインライン名称変更タイマーを無効化し、連動ナビゲーションを解除する。転送キューとエディタ監視はタブ切り替えや終了から独立して継続し、関連処理のあるタブを閉じる前に確認する。
- 表示設定は短い遅延で自動保存し、保存要求は順番に処理する。切り替え・終了時は最新の文書を保存し、通常のウインドウ終了要求は保存完了を待つ。復元エラー時には空の文書を自動保存せず、再試行を提示する。
- タブ操作、再接続、終了確認、復元エラーは英語・日本語・简体中文に対応する。ネイティブの終了処理・実通信は別途実機検証を行う。
