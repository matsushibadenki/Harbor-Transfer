# Harbor Transfer 0.2.6

Published on 2026-10-23: [GitHub Release](https://github.com/matsushibadenki/Harbor-Transfer/releases/tag/v0.2.6).

The universal macOS app and DMG passed Apple notarization. The downloaded updater archive was checked against the embedded public key, contains both Apple Silicon and Intel binaries, and has no AppleDouble entries or extended attributes. The public updater endpoint serves version 0.2.6.

## 日本語

- リスト、アイコン、カラム表示の余白、文字、日付、選択表示と明暗テーマを改善しました。
- アイコン表示にフォルダ・書類の新しいアートと拡張子ラベルを追加し、2行ファイル名と補足情報の配置を整えました。
- カラムの列幅変更、階層の左右キー移動、独立スクロールと情報プレビューを改善しました。
- 素早いフォルダ切り替えで古い読み込み結果が表示される問題を修正しました。
- 狭いウインドウと大きな文字サイズでの表示、範囲選択とキーボード操作を改善しました。

## English

- Refined spacing, typography, dates, selection, and light/dark appearance across list, icon, and column views.
- Added folder and document artwork with extension labels, two-line file names, and improved metadata placement in icon view.
- Improved column resizing, left/right keyboard navigation, independent scrolling, and the file information preview.
- Fixed stale directory responses appearing after switching folders quickly.
- Improved narrow-window layouts, larger text sizes, range selection, and keyboard controls.

## 简体中文

- 改进列表、图标和分栏视图的间距、文字、日期、选择状态以及浅色和深色外观。
- 图标视图新增文件夹和文档图标及扩展名标签，优化两行文件名和补充信息的排列。
- 改进分栏宽度调整、左右方向键导航、独立滚动和文件信息预览。
- 修复快速切换文件夹后显示过期加载结果的问题。
- 改进窄窗口、大字号、范围选择和键盘操作。
